# city-safety-spend

Police and fire spending as a share of city government spending for every US city with 100,000 or
more residents (332 cities), 1967 to 2024, built from the Census Bureau's Annual Survey of State and
Local Government Finances individual unit files and cross-validated against five other sources.

**Live:** https://safetyspend.bristleconeanalytics.com — the dashboard at `/`, the findings piece
"Twenty-Eight Cents" at `/findings.html`, and a fact sheet per city under `/factsheets/`.
Served from Cloudflare as a static-assets Worker (`wrangler.jsonc`); `npx wrangler deploy` from
this directory publishes whatever is in `site/`. Every figure in the piece is generated from
`data/census_out/findings.json`, so the prose cannot drift from the data.

## Start here

- `docs/METHODOLOGY.md`: what the numbers are, the four denominators, the classification rules that
  bite (own pension funds excluded, contract police invisible, fire districts), known source artifacts.
- `validation/REPORT.md`: how the dataset was checked and where it disagrees with other sources, and why.
- `docs/CONVENTIONS.md`: repo rules for anyone extending it.

## The data

| file | what |
|---|---|
| `data/census_out/city_police_fire_2022.csv` | latest full-census year, one row per city, all columns |
| `data/census_out/city_police_fire_all_years.csv` | 2012 to 2024 from our own parse, with Census imputation flags |
| `data/census_out/city_police_fire_1967_2024_long.csv` | the long series; pre-2012 and 2016 rows come from the Willamette compilation (no flags exist for those) |
| `data/census_out/city_flags.csv` | comparability flags: runs schools, county functions, fire external, police contracted, imputed, incomplete |
| `data/census_out/city_employment_all_years.csv` | 2012 to 2025 sworn officers, firefighters, civilians, March payroll, per-1,000 rates, flag classes |
| `data/census_out/city_rpp.csv` | each city's metro area and BEA regional price parity, 2008 to 2024 |
| `data/census_out/peer_groups.csv` | 8 peer cities per city with distance components and a match-quality label |
| `data/census_out/city_county_allocation.csv` | 2012, 2017, 2022: county jails and courts allocated by population share, and police, fire, corrections and courts combined per resident |
| `data/census_out/city_crime.csv` | 2012 to 2024 FBI violent and property crime per 1,000 residents, with coverage and consistency flags |
| `data/census_out/fisc_share.csv` | for 212 cities, the share on the city's own books vs on the Fiscally Standardized City basis |
| `data/annotations.csv` | national and state policy markers drawn on the trend chart |
| `data/known_issues.csv` | source-data problems traced in validation, with evidence (currently St. Louis 2022) |
| `data/cpi/cpi_u_annual.csv` | CPI-U annual averages 1966 to 2025 used for the constant-dollar columns |
| `pipeline/findings.py` | computes every number the findings piece quotes, into `data/census_out/findings.json` |
| `pipeline/findings_page.py` | renders `site/findings.html` from that file, so the prose cannot drift from the data |
| `pipeline/poll_sources.py` | monthly check of all five upstream sources; exit 10 means something new was published |
| `pipeline/rebuild.py` | re-runs the pipeline and writes `validation/REFRESH_REPORT.md`: what was added, whether past years moved, whether any validation headline got worse |
| `site/factsheets/` | a static one-page sheet per city (open `index.html`), regenerated by `pipeline/factsheets.py` |

Every share column says what it divides by (`_pct_general`, `_pct_total`, `_pct_core`,
`_pct_general_ex_edu`). None of them is the "general fund" share quoted in budget speeches; see
METHODOLOGY section 3 before comparing.

## Rebuild

```
python pipeline/build.py
python pipeline/checks.py
python pipeline/compare_willamette.py
python pipeline/compare_fisc.py
python pipeline/compare_vera.py
python pipeline/compare_spotcheck.py
python pipeline/compare_bjs.py
python pipeline/rpp.py
python pipeline/employment.py
python pipeline/employment_checks.py
python pipeline/peers.py
python pipeline/county_alloc.py
python pipeline/compare_county_alloc.py
python pipeline/crime.py
python pipeline/factsheets.py
python pipeline/compare_fbi.py
python pipeline/export_site.py
```

Raw downloads (`data/census_raw/`, `data/*/raw/`) are gitignored and re-downloadable; every source
URL and retrieval date is recorded in `docs/METHODOLOGY.md` and in each `data/<source>/NOTES.md`.
Stdlib Python plus `gdown` for the Willamette file.
